### About me

I'm **Victor**, also known as **OrbitNode**. My strongest focus is frontend engineering, especially building responsive, accessible interfaces with **JavaScript, TypeScript, React, and Next.js**.

I also work across the stack: integrating APIs, implementing application logic with **PHP and Python**, working with databases, and presenting data using **Power BI and Excel**. I'm interested in the intersection of software engineering, useful automation, and computer vision.

I care about writing maintainable code, understanding the problem behind a feature, and building experiences people can actually use.
